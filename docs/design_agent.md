# AI 封面图生成应用需求文档

## 主要功能 (Core Features)

### AI 生成封面图
- **文章摘要**: 用户输入或粘贴一篇文章内容。应用首先使用 Gemini AI (`gemini-2.5-flash`) 将文章内容智能浓缩成一个简短的核心摘要（约120字）。
- **风格融合**: 接着，应用将这个摘要与用户选择的"风格模板"中预设的艺术风格提示词（Prompt）相结合。
- **图片生成**: 最后，调用 AI 绘画模型 (`imagen-4.0-generate-001`) 生成一张符合文章主题和指定艺术风格的、无文字的背景图片。

### 模板化设计与叠加
- **预设模板**: 提供多种预设的封面风格模板（如简约、商务、艺术等）。
- **模板配置**: 每个模板都定义了封面的宽高比（16:9, 1:1 等）、Logo 位置、品牌文案位置、叠加文字颜色，以及最重要的——用于 AI 绘画的风格提示词。
- **图像合成**: AI 生成的图片作为背景，应用会根据所选模板的规则，将品牌 Logo 和品牌文案叠加在图片上，最终合成为完整的封面图。

### 管理与自定义功能
- **独立管理页面**: 提供一个独立的"模板与品牌管理"页面。
- **全局设置**: 用户可以上传自定义的品牌 Logo 图片，并设置全局统一的品牌文案。
- **模板编辑**: 用户可以编辑现有的任何模板。在编辑弹窗中，可以修改模板名称、Logo 和文案的位置、宽高比、文字颜色以及 AI 绘画的风格提示词。
- **实时预览**: 在编辑模板的弹窗中，提供一个实时预览区域，用户在修改设置时可以立刻看到封面的大致布局效果。

### 图形用户界面 (GUI)
- **技术栈**: 使用 React 和 TypeScript 构建，确保类型安全和组件化。
- **样式**: 使用 Tailwind CSS 实现现代化、响应式的布局，并支持浅色和深色两种主题模式。
- **布局**:
  - **首页**: 采用两栏布局，左侧为操作区（文章输入、模板选择、生成按钮），右侧为结果展示区（封面图预览）。
  - **管理页**: 采用清晰的单页设置布局，分为"全局设置"和"模板列表"两个板块。

### 用户体验
- **加载状态**: 在 AI 处理期间，提供明确的加载状态（Loading animations）。
- **错误处理**: 如果生成失败，需要向用户显示清晰的错误信息。
- **数据持久化**: 所有用户设置（文章内容、自定义 Logo、品牌文案、模板修改）都应使用 localStorage 进行本地持久化存储，以便刷新页面或下次访问时保留配置。
